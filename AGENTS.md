# AGENTS.md

## Stack

- Java 21, Spring Boot 3.2.2, Gradle, Lombok
- Deployed as AWS Lambda via SAM (region: `eu-west-3`)
- Generated by [Poja](https://poja.io) — files annotated `@PojaGenerated` are auto-generated, do not edit

## Commands

| Command | Purpose |
|---|---|
| `./gradlew test` | Run all tests (JUnit 5). Uses maxParallelForks = half of CPU cores. |
| `./format.sh` | Format all Java source with google-java-format 1.23.0 |
| `./gradlew test jacocoTestReport` | Tests + JaCoCo HTML/XML coverage report |

Test execution chain: `test -> jacocoTestCoverageVerification -> jacocoTestReport`

## Codebase layout

```
src/main/java/org/coco/add/
├── PojaApplication.java          # @SpringBootApplication entrypoint
├── handler/LambdaHandler.java    # AWS Lambda adapter (aws-serverless-java-container)
├── endpoint/rest/controller/
│   ├── arith/                    # AddController, SubtractController, MultiplyController, DivisionController
│   └── health/                   # PingController, HealthEmailController
└── service/                      # AddService, SubtractService, MultiplyService, DivisionService (handwritten)
```

## Conventions

- **Services are the custom code** — they lack `@PojaGenerated`. The rest of the codebase is auto-generated.
- **Controllers** use `@AllArgsConstructor` (Lombok) + `private final` fields for constructor injection
- **All controllers** follow the same pattern: accept `String a, String b` query params, return `ResponseEntity<?>` with BAD_REQUEST on error
- **Services** require positive integer strings, throw `IllegalArgumentException` with user-facing messages for invalid input
- **Integer overflow is intentionally silently wrapped** (test `should_handle_overflow_silently` confirms this)
- **No application.properties/yml** — config is via `@Value` defaults in `@Configuration` classes

## Testing

- **Tests must extend `FacadeIT`** (`src/test/java/org/coco/add/conf/FacadeIT.java`)
  - Provides `@SpringBootTest(webEnvironment = RANDOM_PORT)`
  - Injects mock AWS properties (dummy S3 bucket, dummy SES source) via `@DynamicPropertySource`
- Test class naming: `<Service>Test` (e.g., `AddServiceTest`)
- Service tests inject the real service with `@Autowired`
